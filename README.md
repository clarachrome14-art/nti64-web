## What Is NTI64?

Ok... We got a little bit to unpack here. So, NTI64 is a native port of SM64 for your browser(Windows, Linux, and Mac support expected in future updates!) that has singleplayer and a whole variety of multiplayer modes. In general, this isn't your usual SM64 web port, as you'll soon see...
## What Seperates This Project Apart From Others?

- This has speedrunning tools, such as save states, pratice modes, tutorials on tech such as BLJ's, and more!

- It is a NATIVE web port, just not an emulator. This makes it deliver the best performance as you can get. It even got a perfect 60FPS performance test on a school Chromebook(Lenovo 300e Yoga Chromebook Gen 4)!

- FREELOOK! WE ACTUALLY HAVE FREELOOK! I have not seen this implemented on any other web port as of typing this.

- Multiplayer. This is an idea that I plan to expand on a LOT more...

- You will automatically recieve updates from your HTML. No need to search on Github just to download the HTML all over again. As long as you got yourself an internet connection that can connect to Github's servers, you should be all set!

- As stated above about the project being native, this does have some really good performance. Along with it though, the physics are exactly on par with the original SM64. So, do all the glitches you want, if it works on the N64, it'll work here(besides multiplayer, the engine does have quite the rewrite to get it to be optimal. Expect not all of the glitches working there).
